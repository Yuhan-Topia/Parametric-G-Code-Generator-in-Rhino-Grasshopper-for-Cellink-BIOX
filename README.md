# Parametric-G-Code-Generator-in-Rhino-Grasshopper-for-Cellink-BIOX
This repository contains a parametric G-code generator developed using Rhino-Grasshopper, tailored specifically for the Cellink-BIOX 3D bioprinter. By combining visual programming with the Human UI plugin, it enables intuitive, high-precision toolpath planning and customized code generation for advanced microstructures.
